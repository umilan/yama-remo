yama-remo

A local web remote for Yamaha MusiCast speakers (built & tested against the NX-N500), plus research on building a physical rotary-encoder hardware remote without soldering.

Get the remote

musiccast-remote.htmlSingle self-contained file, no install Download

Why download instead of a live page here: your speaker's control API is plain, unencrypted local HTTP with no login — by design, since it only works on your own network. Browsers block an HTTPS page (which this one is) from ever fetching a plain HTTP address ("mixed content"), so a version of the remote hosted live here could never actually reach your speaker. Downloading the file and opening it directly (double-click, or drag into a browser) sidesteps that restriction entirely.

Using it

  1. Download musiccast-remote.html above and open it in a browser.
  2. Tap the gear icon (Settings) and enter your speaker's IP address on your LAN.
  3. Close Settings — Power, source buttons (AirPlay / AUX / Bluetooth / USB), the volume dial, and play/pause/next all send commands immediately.
